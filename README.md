## 这个游戏哪里不正常

这里列出的每一条，都是他的原话需求：

**植物可以无限叠种。** 同一个格子可以种 100 万株植物。叠得越多，植物射击越快。格子上会显示 ×N 的徽章。

**F 键可以无限叠加加速。** 每按一次 F，所有植物的射速乘以 3。按三次就是 ×27 倍速，按十次是 ×59049 倍速。没有上限。

**有一种敌人永远打不死。** 游荡者模式里的 👾 游荡者血量是无穷大，任何子弹都只会让它重生在右边。它们在场上漫无目的地乱窜，碰到哪格植物就伤害哪格。坚果墙可以挡住它们，但不能消灭它们。

**玉米加农炮可以同时轰炸无数个目标，永不停歇。** 选中玉米加农炮后，点一只僵尸它就开始无限连发。继续点其他僵尸，炮台会同时对所有目标持续开火。只有按 Esc 才能停下来。

**暂停的时候也可以瞄准。** 游戏暂停后点击僵尸，等恢复运行时炮弹才会飞出去爆炸。

**有一个"全屏随机子弹"模式。** 开启后，每一帧都会在整个棋盘随机位置生成各种随机类型的子弹。没有任何植物在射击，子弹凭空出现。

**僵尸血量是 17000。** 不是 100，不是 400。是 17000。每一只。

**G 和 H 是给僵尸加速 / 减速的快捷键。** 按 G 全场僵尸 ×3 加速，按 H ÷3 减速，可无限叠加。F 是给植物加速的，G H 是给敌人加速的。三个键一起按可以构造任意荒诞速度比。

**输了会被喊一声「No!」。** 僵尸突破最后一道割草机时，除了下行音阶还会用浏览器自带的语音合成喊一声 No —— 和游戏里所有声音一样，没有任何音频文件，全是现场生成的。

**割草机用不完。** 一行一台割草机被僵尸触发清场后，划出屏幕会自动复位重新装填；如果没有可用的，触发时会现场新建一台。永远不会因为"割草机用完了"而判负。

**绿叶素是核武器开关。** 选中绿叶素 💚 点向樱桃 → 满地 5×9 = 45 株随机植物。点向土豆 → 满地铺樱桃，下一帧全部连锁爆炸。点向坚果保龄球 → 保龄球滚过每一格自动种下土豆或樱桃。点向卷心菜投手 → 全场每个僵尸头上各挨一颗巨大卷心菜，从高空越过坚果墙和铁门砸下来，护甲一概无效。点向磁力菇 → 全场僵尸被吸成一条直线，金属护甲当场脱落，然后整行磁场引爆，一人 17000。

**胜利时会种 100 株随机植物庆祝。** 击退所有僵尸后，棋盘上会随机爆满 100 株植物。

**报纸将王开局就在，而且有 6400 万血。** 他是个举着一张大报纸的巨型僵尸，手里那摞报纸就是他的兵源 —— 放出来的全是报纸僵尸。 点「普通版」的那一刻，他已经站在棋盘最右侧
开始放僵尸了 —— 以前的「第一局自动赢」已经去掉，第一局也要正经打。开局第一列不再
白送 5 株随机植物（里面的超级投手 / 黑曜石是秒杀弹，挂机 80 秒就能把他磨死），
现在空场开局，输出得自己种。

## 快速开始

**在线游玩（GitHub Pages）：** https://baojie.github.io/PVZ/

本地运行：

```bash
./run.sh              # 前台启动，默认端口 1644
./run.sh 3000         # 自定义端口
./run.sh -d           # 后台启动
./run.sh restart      # 重启后台服务（端口沿用上次）
./run.sh stop         # 停止
./run.sh status       # 查看状态
```

浏览器打开 `http://localhost:1644`。

## 选卡

每一关开打之前都会弹出**选卡界面**：场上有多少张种子卡就列多少张，点一下选中 / 取消。

- **全选**：所有植物都能用（默认）
- **全不选**：一张卡都不带也能开打，那一关就只能靠割草机和铲子了
- 选择记在 `game.chosenCards` 上，**下一关默认沿用上一关的选择**
- 没选的卡在这一关的种子栏里直接不显示

## 关卡与奖杯

打死报纸将王就算通关，棋盘正中会掉下一个**金奖杯 🏆**，闪着金光等你点。点一下 ——
金光炸开、杯子越涨越大，涨满屏就进入**下一关**。

下一关的将王更硬：血量按关卡线性上涨，第 1 关 6400 万、第 2 关 1.28 亿、第 3 关 1.92 亿……
状态栏左边一直显示当前是第几关。想从头再来就点 🏠 回首页，关卡会归 1。

- 🧲 磁力菇 → 先把全场僵尸远距离击退 280px，再吸成一条直线，扒掉金属护甲后引爆磁场，每个僵尸吃满 17000 点伤害

## 僵尸

**普通模式只有一个报纸将王 📰。** 场上所有僵尸都是他放出来的，打死他才算赢。

他有 6400 万血，循环两个阶段：

| 阶段 | 时长 | 说明 |
|------|------|------|
| 放僵尸 | 10 秒 | **无敌**，植物够不着他。每 0.5 秒从报纸里抖出一只，一波共 20 只，**全是报纸僵尸** |
| 低头 | 8 秒 | 放完一波就低头，把脑袋送到植物打得到的高度 —— 这是唯一的输出窗口 |
| — | — | `J` / `H` 会整体加快 / 放慢上面这两个阶段：按 J 放僵尸更密、低头来得更快（低头那 8 秒也过得更快），按 H 反过来 |
| 冻住 | 看寒冰 | 被寒冰菇的爆炸或寒冰射手的子弹冻住时，相位和放僵尸计时**全停**，而且他停在原地，照样打得到 |

也就是说：没低头的时候、以及低头结束后的 10 秒里，你都打不到他，他会一直往外放僵尸。

**每只僵尸 800 血，血量直接显示在头顶**（血条 + 数字）。水滴 / 黑曜石 / 超级投手这类「秒杀」子弹打将王时按 800 折算，不会一发拆了他；每颗子弹对将王只结算一次伤害。

例外是超级电能机枪豌豆 ⚡：电能弹对僵尸是无限点伤害，打将王的基数是 1800（不是 800），而且**只有它**吃逐发 +15% 的递增，封顶 18000。

| 僵尸 | 特点 |
|------|------|
| 🤖 报纸将王 | 普通模式的 Boss，6400 万血。放僵尸时无敌，低头 8 秒时可被攻击 |
| 🧟 普通 / 🔶 路障 / 🪣 铁桶 / 📰 报纸 / 🎿 撑杆 / 🚪 铁门 | 每只 800 血，由将王从弱到强依次放出 |
| 👾 游荡者 | 永生，四处乱窜，伤害所经过格子的植物（仅游荡者模式） |

想调他的节奏，改 `classes/Boss.js` 顶部的 `SPAWN_PHASE_MS` / `BOW_MS` / `ZOMBIES_PER_WAVE` / `BOSS_HP` 即可；出场顺序在 `STRENGTH_ORDER`。游荡者模式不受影响，仍走 `WandererSystem`。

## 操作

| 操作 | 效果 |
|------|------|
| 点击种子卡 → 点击格子 | 种植植物 |
| 点击 🪏 → 点击格子 | 铲除该格所有植物 |
| 点击 🌽 → 点击僵尸 | 玉米加农炮瞄准并无限连发 |
| `Space` | 暂停 / 继续 |
| `F` | 植物加速（可叠加，每按一次 ×3） |
| `G` | 全场僵尸加速 ×3（可叠加） |
| `H` | 全场僵尸减速 ÷3，同时报纸将王整套节奏也慢 ÷3（可叠加） |
| `J` | 报纸将王节奏 ×3：放僵尸更密，低头也来得更快（可叠加） |
| `Esc` | 取消选择 / 退出瞄准模式 |

## 游戏设置

开始前可在设置面板调整：

- **初始阳光**：50 / 150 / 300 / 无限（当前所有植物均免费，阳光仅作展示）
- **总波数**：3 / 6 / 9 波
- **僵尸数量**：少 / 正常 / 多 / 超多（×0.5 ~ ×4）
- **僵尸速度**：滑块 ×0.5 ~ ×3
- **全屏随机子弹**：开启后每帧在全场随机生成子弹（默认关）
